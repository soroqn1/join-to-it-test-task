# Test Task Reference

## Original Task
> Ты делаешь бэкенд для управления событиями (конференции, митапы и т.п.) на Django. Это не сайт с кнопками, а REST API — набор адресов, к которым обращается любой клиент (фронтенд, мобильное приложение, Postman) и получает JSON.
> 
> Что умеет система:
> - Пользователи — регистрируются и входят по email. После входа получают токен (JWT), который прикладывают к каждому запросу, чтобы система понимала, кто это.
> - События — залогиненный пользователь может создать событие (название, описание, дата, место). Он становится его организатором. Редактировать и удалять событие может только сам организатор — чужое трогать нельзя. Смотреть события могут все залогиненные.
> - Регистрация на события — пользователь нажимает «участвую» и записывается на чужое событие. Записаться дважды на одно и то же нельзя. Можно отменить участие.
> 
> Три сущности и связь между ними:
> `Пользователь` создаёт `События` и записывается на них через `Регистрации`. Регистрация — это мостик между пользователем и событием.
> 
> Бонусы, которые заложены:
> - Поиск и фильтры — найти события по названию, месту, дате, организатору.
> - Email при регистрации — записался на событие → на почту приходит письмо.
> 
> Обёртка вокруг всего:
> - Документация API (Swagger) — живая страница, где видны все запросы и можно их потыкать.
> - Docker — весь проект (приложение + база PostgreSQL + Redis) поднимается одной командой, без ручной установки.
> 
> По сути это тестовое на «умеешь ли ты собрать нормальный бэкенд»: модели, права доступа, аутентификация, документация, контейнеризация. Всё требования из задания закрыты, плюс оба бонуса.

## Interpretation & Requirements Checklist
- [ ] **Framework**: Django REST Framework.
- [ ] **Auth**: JWT based on Email, not Username.
- [ ] **Entities**: User, Event, Registration.
- [ ] **Permissions**: 
  - Anyone (authenticated) can view events.
  - Anyone (authenticated) can create events.
  - Only organizer can edit/delete their event.
  - Users can join/leave events.
  - Cannot join the same event twice.
- [ ] **Search & Filters**: Title, Location, Date, Organizer.
- [ ] **Async Tasks**: Email on registration via Celery/Redis.
- [ ] **API Docs**: Swagger via `drf-spectacular`.
- [ ] **Deployment**: Docker Compose (App, Postgres, Redis, Celery).
